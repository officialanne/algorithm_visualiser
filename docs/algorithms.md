# Algorithms and data structures

- Bubble, selection, and insertion sort return visual steps while sorting a copy of the input.
- Linear search visits elements in order.
- Binary search works on a sorted copy, showing the low, middle, and high positions.
- Stack uses LIFO operations: push, pop, and peek.
- Queue uses FIFO operations: enqueue, dequeue, and front.

The visualizer is designed for learning rather than benchmarking: all animations deliberately pause between recorded operations.
