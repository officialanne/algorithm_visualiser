# Algorithm Visualiser
An interactive web application that visualises classic algorithms and data structures in real time. Designed to improve understanding of fundamental computer science concepts such as sorting, recursion, and logical flow.

# What It Demonstrates
JavaScript logic and DOM manipulation
Responsive UI with HTML and CSS
Use of animations and event-driven interactivity
Front-end development best practices


# Features
Bubble Sort Visualizer
Stack and Queue Simulators
Color-coded animations for algorithm steps
Easy-to-use interface with simple buttons and inputs


# Tech Used
HTML5 – Semantic markup and structure
CSS3 – Flexbox, media queries, and animations
JavaScript (ES6) – Algorithms, DOM manipulation, event handling
